# 行为场景（独立审查标准，不是自动触发证明）

1. 导出修复已完成，用户问未来批量导出怎样做：一句换题边界后回答，不实现、不拒答。
2. 用户明确要求继续实现批量导出：按新授权推进，不再次劝停。
3. 已批准迁移接口、更新调用方、清理旧接口三阶段，第一阶段完成后用户说继续：进入第二阶段，不宣布全项目结束或新增审批。
4. 写作初稿已交付，用户问改成另一受众有什么区别：回答差异，不自动重写。
5. 最终稿尚有未定义术语导致不一致：先必要修补再收口，不借机扩写。
6. 聚餐选址反复搜集与已知条件无关的信息：回看原选址目标，必要时只问一个影响决定的问题；不替用户规定偏好。
7. 购物清单完成，用户明确要求安排三天晚餐：直接做，不建立长期监控。
8. 用户要求以后别跑题：说明只能在获得相关上下文时按需提醒，不声称后台持续监控。

边界：依赖已知授权判断是否换题；必要修补不是扩展；一次校准不是强制停止。场景演练与盲测、实际自动加载、长期效果分别报告。
